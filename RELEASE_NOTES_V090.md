# Student Hub v0.9

Planner is now a multi-view academic command center rather than a seven-column task wall. The key product change is separation of **time perspective** (Week / Month / Agenda) from **decision lens** (Plan / Deadlines / Courses), with filters and progressive disclosure so detailed task blocks are visible only when needed.

Smart planning is now human-in-the-loop: Student Hub previews proposed sessions before writing them to Appwrite. The release also includes a safe plan-repair tool for legacy adaptive blocks that violate planning windows, exceed remaining effort, or overload a week.
