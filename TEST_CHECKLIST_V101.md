# Student Hub v1.0.1 test checklist

After GitHub Pages deploys, do a hard refresh (`Ctrl + Shift + R`) once.

## Today
- [ ] Today shows dates/times in English even if Chrome is using Russian.
- [ ] If there are missed study blocks this week, the status button says **Review slipped work**.
- [ ] Clicking it opens the plan recovery modal.
- [ ] The modal lists Student Hub-generated slipped sessions.
- [ ] **Clean up & replan** removes only eligible generated planner blocks.
- [ ] A replacement Smart Plan preview appears before replacement sessions are saved.
- [ ] Fixed classes, deadlines, completed sessions and manual blocks are not silently deleted.

## Planner
- [ ] Week, Month and Agenda still render.
- [ ] Previous/next period arrows still work.
- [ ] Timetable / deadline / course filters still work.
- [ ] Dates and weekdays remain English.

## Study
- [ ] Focus target dropdown contains Free focus and available planner work.
- [ ] Selecting a planner task updates the focus title/course/topic.
- [ ] Free focus lets you choose a course context.
- [ ] 15, 25, 45 and 60 minute presets work.
- [ ] −5 and +5 work while the timer is paused.
- [ ] Duration controls are disabled while the timer is running.
- [ ] Reset returns to the currently selected duration.
- [ ] Full screen focus hides the normal app navigation and secondary study content.
- [ ] Exit full screen / Escape returns to the normal Study page.
- [ ] Finish & save records the elapsed study session.
- [ ] Relevant materials still open from the session context.

## Inbox
- [ ] Capture textarea works.
- [ ] Capture button is compact rather than full textarea height.
- [ ] New captures sync and appear in Process later.
- [ ] Process and Archive still work.

## Regression
- [ ] Sign in / account creation still work.
- [ ] Courses still load and open.
- [ ] Library PDFs still open/delete.
- [ ] Syllabus AI import still works.
- [ ] Smart Plan still creates work blocks.
