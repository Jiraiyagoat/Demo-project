Cloud QA reset - v1.0.7

This tool works against the currently signed-in Student Hub Appwrite account. It is for a repeatable, realistic end-to-end test workspace - not the local demo fixture.

Destructive to the active semester. Reset removes the current semester's courses, assessments, tasks, planner blocks, resources, Inbox items and study sessions, then seeds fresh QA records. It keeps your account and semester row. A JSON metadata backup is downloaded first. Stored PDF/file bytes are deleted only if you explicitly enable that checkbox.

2. Reset and seed

Choose whether to start completely empty for your own real syllabi/files, or seed a realistic QA semester. The QA seed has 4 real cloud courses, recurring schedules, 9 deadlines, planner tasks, future study blocks, one intentionally slipped block, Library notes/links, Inbox captures and study history. Dates are relative to the day you run it.
